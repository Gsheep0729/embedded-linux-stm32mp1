# 嵌入式 Linux 学习笔记与博客原稿（FS-MP1A / STM32MP157）

基于**华清远见 FS-MP1A 开发板（ST STM32MP157AAA3）**的嵌入式 Linux 课程学习仓库：既是课程课件的 Markdown 图文存档，也是同名技术博客专栏的原稿库。

## 仓库里有什么

| 目录 | 内容 |
|---|---|
| `PPT/` | 10 章课件 PPT → Markdown 图文完整版（配图按章归档于 `PPT/images/chapNN/`） |
| `01_移植U-Boot/` | 博客原稿：第 3 章「移植 U-Boot」实验系列（实验导论 + 各实验指导，指导与真实终端记录合二为一） |
| `CLAUDE.md` | 仓库内部维护约定（AI 协作工作流说明），浏览内容可忽略 |

> 原始 `.dps/.pptx` 课件与 SDK 安装包体积较大，未入库（见 `.gitignore`）。

## 文档特点

- **实验驱动**：每篇都是「这步做什么 → 为什么这么做 → 为后续铺垫什么」的写法，不是命令罗列；
- **真实记录**：终端输出、报错、踩坑全部保留——包括失败案例（如未激活工具链时 `-mtune=generic-armv7-a` 报错的定位方法）；
- **命名规范**：博客文档统一 `NN_短标题.md`（NN 即阅读顺序），并按课件章节归入章节目录（如 `01_移植U-Boot/`）；图片按 Typora 规则放在同名 `.assets/` 文件夹、按阅读顺序命名（`01_xxx.png`），克隆后可直接用 Typora 打开阅读。

## 实验环境速览

| 项目 | 配置 |
|---|---|
| 开发板 | 华清远见 FS-MP1A V3.1（STM32MP157AAA3：双核 Cortex-A7 + 单核 Cortex-M4） |
| 虚拟机 | VMware + Ubuntu 20.04（4GB 内存） |
| 工具链 | ST OpenSTLinux SDK 3.1（dunfell-mp1-20-06-24），交叉编译 `arm-ostl-linux-gnueabi-` |
| 引导链 | TF-A + U-Boot（先 basic 后 trusted） |

## 路线图

- F-1~F-6：按串口报错迭代修复（电源 → SD 检测 → ADC → 显示 → 网卡 → eMMC）
- trusted 版 U-Boot 移植
- 第 4~10 章实验：U-Boot 使用、Linux 内核移植、根文件系统（BusyBox/Buildroot）、字符设备驱动、GPIO、设备树、Qt GUI
