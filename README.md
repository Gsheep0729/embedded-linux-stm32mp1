## 文档特点

- **实验驱动**：每篇都是「这步做什么 → 为什么这么做 → 为后续铺垫什么」的写法，不是命令罗列；
- **真实记录**：终端输出、报错、踩坑全部保留——包括失败案例（如未激活工具链时 `-mtune=generic-armv7-a` 报错的定位方法）；
- **命名规范**：博客文档统一 `NN_短标题.md`（NN 即阅读顺序），并按课件章节归入章节目录（如 `01_移植U-Boot/`）；图片按 Typora 规则放在同名 `.assets/` 文件夹、按阅读顺序命名（`01_xxx.png`），克隆后可直接用 Typora 打开阅读。
